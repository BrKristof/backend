npm i -D tsc
tsc ./src/index.ts
npx tsx ./src/index.ts      ezzel is futtathato a ts
node ./src/index.ts

nodejs legfrissebb verzio kell

npm: node csomagkezelo

"dev": "nodemon --exec node ./src/index.ts"

akkor lefut az index.ts es real time updatel
